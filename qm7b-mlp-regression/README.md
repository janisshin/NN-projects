# QM7b MLP Regression

A neural-network regression project using the QM7b molecular dataset to predict atomization energy from molecular composition features.

This project originated as a course exercise in MSE 542. The original notebook is preserved here as `training_experiments.ipynb` and will be cleaned into a concise, reusable implementation while retaining the original source repository as provenance.

Original source: https://github.com/janisshin/MSE541
